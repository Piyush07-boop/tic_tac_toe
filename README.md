
# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. This project allows two players to play against each other in a classic 3×3 grid.

## 🚀 Live Demo

[Play Tic Tac Toe](YOUR_LIVE_DEMO_LINK)


## ✨ Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Automatic winner detection.
- Detects draw situations.
- Reset button to start a new game.
- Clean and user-friendly interface.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and interactivity.

## 🎯 How to Play

1. Player 1 uses X.
2. Player 2 uses O.
3. Players take turns selecting empty cells.
4. The first player to get three marks in a row, column, or diagonal wins.
5. If all cells are filled and nobody wins, the game ends in a draw.
